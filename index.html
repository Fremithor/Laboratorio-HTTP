Redes de Computadores

Sitio web estático que muestra cómo HTTP permite solicitar y entregar recursos entre navegador y servidor.

Conocer al equipo

HTTP en la capa de aplicación

HTTP es el protocolo que utiliza el navegador para solicitar archivos al servidor. En este proyecto, el servidor entrega documentos HTML, estilos CSS e imágenes para formar el sitio completo.

  • Solicitudes y respuestas HTTP.
  • Relación entre el modelo OSI y TCP/IP.
  • Direccionamiento IPv4 e IPv6.
  • Simulación de redes con Packet Tracer y GNS3.
